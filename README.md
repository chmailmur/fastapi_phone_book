ТЕЛЕФОННЫЙ СПРАВОЧНИК 

FastAPI приложение «Телефонный справочник». 
Проект предназначен для просмотра, создания котактов которые сохраняются как список объектов.

============================================================

ВОЗМОЖНОСТИ

Просмотр всех контактов

Добавление нового контакта

Хранение данных


============================================================

ФОРМАТ ХРАНЕНИЯ ДАННЫХ

Контакты хранятся в списке объектов:

name — имя контакта
phone — номер телефона
age — возраст

ЗАПУСК ПРИЛОЖЕНИЯ

Установка

Проверить версию docker

docker --version

Пройти в каталог fastapi_phone_book

cd fastapi_phone_book

Собрать Контейнер

docker build -t fastapi-app .

Запуск 

docker run -p 8000:8000 fastapi-app

В праузере перейти по адресу http://localhost:8000
